# AI Travel Planner (Dubai)

Multi-Agent System that converts a natural-language travel request into a complete, budget-aware, day-by-day Dubai itinerary.

## Overview

This project uses LangGraph and dual LLMs (Gemini for parallel agents, Groq for Review) to process complex travel planning constraints into a structured itinerary.

See `Docs/architecture.md` for full system design.
